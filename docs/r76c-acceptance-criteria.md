# R76C Acceptance Criteria

1. A Creator applicant does not need approved AKARI House membership to apply to an open Ambassador Campaign.
2. A valid primary X profile is required.
3. X follower count must be present. Zero is valid; missing is not.
4. XScore and Sorsa score must be present and available.
5. The application snapshots X URL, follower count, XScore and Sorsa score.
6. The campaign owner can see those snapshot metrics during applicant review.
7. Existing users and existing campaign applications remain compatible.
8. No follower minimum is introduced.
