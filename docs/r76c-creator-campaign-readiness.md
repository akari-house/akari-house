# R76C Creator Campaign Readiness

R76C keeps campaign participation separate from AKARI House membership approval.

A signed-in user with the Creator role can apply to an open Ambassador Campaign when the Creator has:

- a valid primary X profile
- an X follower count value present, including zero as a valid value
- XScore present and available
- Sorsa score present and available

There is no minimum follower threshold.

When a Creator applies, the campaign application snapshots the Creator's X URL, follower count, XScore and Sorsa score so the campaign owner reviews the metrics that existed at application time.

Missing follower data remains distinct from a real follower count of zero. Existing campaign applications remain readable and are not rewritten by this release.
