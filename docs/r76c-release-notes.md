# R76C Release Notes

- Creator campaign participation remains independent from AKARI House membership approval.
- New campaign applications require a valid primary X profile, follower count, XScore and Sorsa score.
- No minimum follower threshold is introduced.
- Missing follower data is no longer silently treated as zero for a new application.
- Campaign owners can review the snapshotted X follower count, XScore and Sorsa score captured at application time.
- Existing campaign applications are preserved.
