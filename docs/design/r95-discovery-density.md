# R95 — Discovery Density & Project Media

Goal: make discovery surfaces compact and scannable without changing AKARI House product boundaries or existing data.

## Members

- Keep List as the dense operational default.
- Reduce desktop member rows to roughly one-screen scanning density.
- Keep avatar, identity, role, headline/expertise, profile action and connection status visible.
- Preserve Cards as the alternate visual view.
- Preserve profile privacy and connection rules.

## Projects

- Reuse the existing project `banner_key` and project brand media route.
- Show uploaded Deal Room banners in project discovery cards.
- Use a denser 3/2/1 responsive grid on desktop/tablet/mobile.
- Clamp summaries and visible support-need chips so directory cards remain discovery surfaces rather than detail pages.
- Preserve the full project page for complete information.

## Non-goals

- No D1 migration.
- No destructive data changes.
- No CRM changes.
- No redesign of individual profile or project detail pages.
