# Investor House menu map

- **Discover** — published opportunity listings and public previews.
- **Saved** — the signed-in Investor's saved records from `opportunity_user_states`.
- **Requests** — the Investor's latest pending `data_room_requests`.
- **My Deal Rooms** — active approved requests that have not expired.
- **Investor profile** — sectors, stages, geographies, ticket range, experience note and verification submission stored in `investor_profiles`.
- **Updates** — persisted member notifications.

The Deal Room route independently rechecks Investor verification, listing status, request state, grant expiry and document grants. Menu visibility is not treated as authorisation.
